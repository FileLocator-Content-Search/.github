# FileLocator Pro — content search on disks you own

FileLocator Pro keeps one named board on the desk: the live query, the filter in front of you, and a short note the next person can read. Extra hunts wait for their own title.

## Session Card

| Slice | What you do in FileLocator Pro | What remains |
|-------|------------------------|--------------|
| Arrival | Open FileLocator Pro and name today's find desk | A titled query |
| Focus | Keep only live filters on the FileLocator Pro board | A short disk list |
| Check | Read FileLocator Pro own disks before a large search change | A confirmed find desk |
| Handoff | Mark finished queries inside FileLocator Pro | A note for the next person |

## How FileLocator Pro Sits

FileLocator Pro does not replace a slow Explorer hunt, the unlabeled filter dump, or a search aimed at disks you do not own. It sits beside them as a named find desk for one job: which content search is live, which filters still match disks you own, and what the next person should read.

A first visit should be one short content search on disks you own, then the same FileLocator Pro find desk the next day. That is enough to see if the named content filters hold.

## Traffic Light

| Signal | On the FileLocator Pro board | What you do |
|--------|----------------------|-------------|
| Green | Named query, short live filter list | Continue the same content search |
| Amber | Two hunts mixed on one filter set | Split the query before a large change |
| Red | No title, no note, a slow Explorer hunt | Stop and name the find desk first |
| Clear | Handoff written, live filters few | Close FileLocator Pro and leave the find desk |

## Open Order

1. Open the last FileLocator Pro find desk, not a new empty query.
2. Read the filters and the last handoff.
3. Finish one visible content search inside FileLocator Pro on disks you own.
4. Write what changed, then close with fewer Explorer hunts than you found.
5. If the query feels crowded, drop anything that belongs to a different FileLocator Pro hunt.

## After a Week

A week in FileLocator Pro is not a larger slow Explorer hunt. It is the same title, a shorter live filter list, and a note that still makes sense before the next query. Take finished searches off the live set so the next visit starts on the find desk that is still open.

## Sign-off

- [ ] The FileLocator Pro workspace name is short enough to scan
- [ ] Only disks you own sit on the content search
- [ ] A second person can read the filter handoff
- [ ] The last FileLocator Pro query still opens after a restart
- [ ] Finished queries are off the live FileLocator Pro set

## Field Note

FileLocator Pro is easier to trust when the find desk stays smaller than the Explorer-hunt pile it came from. Name the query, keep the live filters, finish one visible content search, and write what changed.
